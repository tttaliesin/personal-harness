# Design

## Context

저장소 루트의 npm 진입점과 Task 명령은 현재 Windows 사용자 프로필에 적용할 파일과 도구를 관리한다.
자체 플러그인 세 개의 공개 설치 경로는 별도 Codex 카탈로그에서 이미 관리한다.

## Goals / Non-Goals

설치 명령은 단독 스킬에는 표준 `skills` CLI를, 자체 플러그인에는 Codex 마켓플레이스를 사용한다.
작업 범위는 저장소의 소스, 배포 파일 및 검사다.
각 PC의 기존 사용자 설정과 설치 기록은 해당 환경에서 관리한다.

## Decisions

- `skills/` 아래에서 자체 스킬과 외부 도구 호환 어댑터를 관리한다. 로컬 참조와 런타임 파일은 각 `SKILL.md` 옆에 함께 배포한다.
- `external-resources.toml`은 외부 리소스의 출처와 갱신 기준을 기록한다. 사본과 설치 상태는 해당 사용처가 관리한다.
- 루트 `npm test`는 카탈로그가 가리키는 실제 파일을 검사한다. 현재 공개 `release/`의 버전과 디렉터리 해시를 확인하고 repo-governance 자체 무결성 매니페스트를 검증한다.
- 설치기와 같은 수명을 가진 검증은 설치기 소스와 함께 제거한다. 플러그인별 빌드와 테스트는 각 패키지에 둔다.

## Migration Plan

새 환경은 README의 표준 설치 명령으로 스킬과 플러그인을 선택한다.
이전 자동 적용 명령을 계속 사용하는 환경은 해당 설치기를 제공했던 Git 커밋에서 실행할 수 있다.
