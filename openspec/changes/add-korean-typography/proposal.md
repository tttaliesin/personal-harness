# Proposal

## Why

현재 디자인 스킬의 영문 중심 폰트 선택만으로는 한글의 실제 서체와 조판을 결정할 수 없다.
한국어 화면에서 브랜드에 맞는 서체, 혼합 문자열과 줄바꿈을 다루는 지침이 필요하다.

## What Changes

- 한국어 웹·앱 UI에 자동 선택하는 `korean-typography` 스킬을 추가한다.
- 실제 한글 지원 서체, 로딩과 줄바꿈의 참고 자료를 포함한다.
- 공통 지침에는 선택 조건과 기존 브랜드·원본 보존 기준만 둔다.
- 설치기에 사용자 스킬의 전체 참조 디렉터리 배포를 연결한다.
- 두 PC에 적용하고 실제 스킬 로딩과 원본 보존을 확인한다.

## Capabilities

### New Capabilities

- `korean-web-typography`: 한국어 화면에 맞는 서체·조판 선택과 실제 렌더링 확인.

### Modified Capabilities

없음.

## Impact

사용자 지침, 저장소 소유 스킬의 배포와 문서에 영향을 준다.
기존 프로젝트의 스택·브랜드 토큰과 repo-governance는 유지한다.
Taste Skill 원본과 시스템 전체 폰트는 수정하지 않는다.
