# Design

## Context

Taste Skill 원본에는 영문 중심의 폰트 조합과 자간 값이 들어 있다.
실제 한국어 글리프가 해당 서체에서 그려지는지는 선언 이름만으로 확인되지 않는다.
기존 설치기는 저장소 소유 사용자 스킬과 외부 원본 스킬의 출처를 구분한다.

## Goals / Non-Goals

**Goals:**
한글 UI 작업에만 상세 조판 지침을 읽게 하고 브랜드·언어에 맞는 선택을 지원한다.
한글 지원 서체의 공식 출처와 실제 표시 확인 방법을 제공한다.

**Non-Goals:**
모든 한국어 대화에 지침을 로드하거나 모든 페이지의 서체를 통일하지 않는다.
OS 폰트 설치, Taste 원본 수정과 repo-governance 변경은 포함하지 않는다.

## Decisions

### 자동 선택 가능한 사용자 스킬

공통 지침에는 선택 조건과 원본 보존 기준을 둔다.
구체적인 판단은 `korean-typography`와 필요한 참조 자료를 읽을 때 로드한다.
등록 목록은 외부 플러그인을 늘리는 대신 기존 사용자 스킬 배포 목록을 사용한다.

### 기존 브랜드와 문자 범위 우선

후보 서체는 역할별 대안으로 제공한다.
어절 단위와 글자 단위 줄바꿈을 모두 허용하고 실제 폭·문구로 선택한다.
크기·행간 범위는 제작 출발점이며 표준이나 품질 통과 조건이 아니다.

### 렌더링 확인

실제 font usage와 CSS 선언을 구분한다.
격리된 브라우저의 한국어 표본에서 웹폰트 glyph 사용과 좁은 화면 overflow를 확인한다.
이 표본은 시각적 선호나 모든 제품에 대한 성능 우위를 입증하지 않는다.

## Risks / Trade-offs

스킬 선택 가능 상태는 모든 요청에서 선택된다는 보장이 아니다.
폰트 배포 주소와 버전은 변할 수 있어 선택 시 원본 CSS·파일을 확인한다.
한글 지원과 실제 읽기 경험은 서로 다른 확인 항목이다.

## Migration Plan

임시 프로필에서 전체 참조 디렉터리 복사와 반복 적용을 검증한다.
기존 사용자 지침과 새 스킬만 백업 후 두 PC에 적용한다.
config·lock·원본 Taste·repo-governance 보존과 새 런타임의 스킬 로딩을 확인한다.
