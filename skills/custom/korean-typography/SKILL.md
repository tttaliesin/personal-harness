# 한글 웹 타이포그래피

결과물의 언어와 독자를 기준으로 한글 조판을 적용할 화면과 구간을 정한다.
사용자의 요청과 기존 브랜드·디자인 시스템을 우선한다.

작업에 해당하는 참조만 읽는다.

- 서체 선택, 폴백 또는 웹폰트 로딩을 다룰 때 [서체 후보와 로딩 기준](references/fonts.md)을 읽는다.
- 크기·행간·자간, 한글과 영문의 혼용 또는 줄바꿈을 다룰 때 [한글 조판 적용 패턴](references/patterns.md)을 읽는다.
- 실제로 렌더링된 글꼴과 글리프 또는 로딩 전후 화면을 확인할 때 [글리프 검증](references/glyph-review.md)을 읽는다.

화면 구성이나 전반적인 시각 디자인이 작업 범위에 포함될 때 해당 디자인 스킬을 함께 선택한다.
서체와 조판 변경은 대상 프로젝트에 한정하고 기존 폰트 토큰과 스타일을 활용한다.
영문용 기본값과 충돌하면 한국어 결과물의 요구를 우선한다.
검증은 작업에 맞는 기존 검사 범위와 판정 기준을 따른다.
