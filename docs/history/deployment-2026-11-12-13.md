## 비공개 한 명령 설치 검증 결과

2026년 11월 13일 비공개 GitHub 기능 브랜치의 npm Git 패키지로 신규 설치와 갱신을 검증했다.
호출 위치는 저장소 밖의 임시 폴더였다.
사용자 홈, Codex 홈, 설치 루트와 상태 루트는 모두 검증용 임시 경로로 지정했다.
직접 clone 명령과 전역 Task 설치는 사용하지 않았다.

신규 설치는 Python을 자동으로 찾아 가상환경과 필요한 패키지를 준비했다.
이어서 공식 최신 안정판을 조회하고 도구와 플러그인을 설치했다.
Harness 파일 13개를 적용한 뒤 `check`에서 변경 파일 0개와 누락 의존성 0개를 확인했다.

| 구성 | 실제 설치와 실행 확인 |
|---|---|
| agent-desktop | `1.3.0`, 실행 파일 SHA256과 버전 명령 확인 |
| CodeGraph | `1.6.2`, npm integrity와 버전 명령 확인 |
| pstack | `0.9.138`, 공식 commit과 설치 내용의 fingerprint 확인 |
| EGM | `0.1.1`, 공식 commit과 설치 내용의 fingerprint 확인 |

같은 상태의 일반 갱신과 `--locked` 갱신도 성공했다.
`--locked` 갱신은 상태 잠금과 로컬 경로, 로컬 설정의 주석과 값, 기존 가상환경 경로를 유지했다.
TOML의 줄바꿈은 기존 편집기의 정규화 동작을 허용해 비교했다.
도구와 가상환경의 경로는 npm 캐시와 버전별 소스 사본을 가리키지 않았다.
임시 런타임 설정과 프로젝트 신뢰 표식도 적용 전후에 같았다.

공백, 작은따옴표와 `&`가 포함된 상태 경로에서 도구를 실제로 실행했다.
npm이 생성한 CodeGraph 실행 파일의 경로 변수는 인용해 설치한다.
공식 CodeGraph 패키지 소스는 변경하지 않는다.

전체 `task test`는 112개 중 111개가 통과했다.
기존 Windows 파일 심볼릭 링크 권한 테스트 1개는 제외했다.
실제 Junction 검사와 새 진입점의 경로 충돌·실패·재실행·동시 실행 검사는 통과했다.

이 절은 임시 프로필의 실제 설치 결과다.
이 검증으로 Homelab과 Roylabs의 실제 사용자 프로필을 다시 적용하지 않았다.
