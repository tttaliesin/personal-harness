# 한글 타이포그래피 지침 적용 결과

2026년 11월 16일 `korean-typography` 사용자 스킬과 공통 선택 지침을 두 PC에 적용했다.
한국어 웹·앱 UI를 만들거나 시각적으로 검토할 때 모델이 선택하도록 구성했다.

## 작성한 지침

기존 브랜드 서체와 디자인 토큰을 우선한다.
한글 서체의 실제 문자 범위, 영문·숫자 혼합, 역할별 행간·자간과 모바일 줄바꿈을 다룬다.
CSS에 적힌 font-family와 실제 한글 글리프를 그린 폰트를 구분한다.
폰트 후보는 제품 맥락에 맞춰 선택하며 한 종류를 모든 페이지에 강제하지 않는다.

후보에는 Pretendard, SUIT, Noto Sans KR, Noto Serif KR와 마루 부리를 포함했다.
공식 출처, 정확한 CSS 패밀리, 라이선스와 배포 방식의 주의점을 참조 문서에 기록했다.
본문·제목의 크기와 행간 범위는 조정 가능한 출발점으로 명시했다.
일반 한국어 대화나 영문 결과물에는 이 스킬을 강제하지 않는다.

## 실제 배포

| 항목 | Homelab Desktop | Roylabs Desktop |
|---|---|---|
| 사용자 스킬과 참조 | 3개 파일 적용 | 3개 파일 적용 |
| 새 런타임의 활성 로딩 | 성공 | 성공 |
| 스킬 로딩 오류 | 0 | 0 |
| 추가 자동 hook | 0 | 0 |
| 최종 적용에서 보존한 파일 | 1,666개 | 1,745개 |

두 PC의 스킬·참조 3개 파일과 사용자 지침 SHA256이 일치했다.
보존 대상에는 기존 config·의존성 lock·PC별 경로·Taste 원본·repo-governance와 hook 파일이 포함된다.
폰트 바이너리는 배포하지 않았다.
Homelab의 `task check`는 변경 0개와 누락 의존성 0개를 반환했다.

Roylabs의 첫 적용은 config.toml 동시 해시 변화로 실패해 추가 지침·스킬만 되돌렸다.
검사 결과 나머지 보존 대상은 동일했다.
해당 배포 코드는 config에 쓰지 않으며 실제 변경 주체는 확인하지 않았다.
현재 config가 안정된 것을 확인하고 그 상태를 보존하며 재적용했다.

## 검증

`task test`는 281개 테스트를 실행해 성공했다.
환경 조건에 따른 2개 테스트는 건너뛰었다.
임시 프로필 검증은 전체 참조 디렉터리 복사, 지속 상태의 이전 복사본보다 현재 소스 우선, 반복 적용과 설정 보존을 포함했다.
공식 skill validator는 UTF-8 모드에서 스킬을 통과시켰다.
독립 검토는 영문 결과물 요청, 기존 브랜드 명조, 좁은 표와 긴 식별자, 잘못 해석한 폰트 readiness 사례를 확인했다.
이 검토는 모델의 자연어 선택률을 측정한 실행 평가가 아니다.

격리된 브라우저 표본에는 공식 Pretendard 1.3.9 가변 WOFF2를 연결했다.
360px와 1280px에서 CDP의 실제 글꼴 사용 정보가 한글 표본 19 glyph를 Pretendard Variable 웹폰트로 표시했다.
두 폭 모두 가로 overflow가 없었다.
다른 대체 글꼴을 쓰도록 바꾼 표본에서도 가로 overflow가 없었다.
모바일 스크린샷으로 제목·본문·입력창·버튼 배치를 확인했다.
이 표본과 글꼴 파일은 Git에 포함하지 않았다.

## 검증의 한계

작성·배포·로딩과 제한된 표본의 렌더링을 확인했다.
모든 제품의 가독성, 디자인 선호도나 개발 완료 시간의 개선을 입증하지 않았다.
실제 작업에서는 선택한 브랜드 서체와 콘텐츠로 화면을 확인한다.
